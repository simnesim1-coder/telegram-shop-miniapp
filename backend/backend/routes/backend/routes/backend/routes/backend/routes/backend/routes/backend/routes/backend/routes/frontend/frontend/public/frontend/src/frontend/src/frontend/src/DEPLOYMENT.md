# Развёртывание Telegram Shop Mini App на Railway

### Загружаешь код
Все файлы уже загружены на GitHub.

## Шаг 2. Railway Setup

### Регистрация и подключение GitHub
1. Открой https://railway.app
2. **Start Project** → **Deploy from GitHub**
3. Авторизируйся через GitHub
4. Выбери **simnesim1-coder/telegram-shop-miniapp**
5. Railway автоматически обнаружит `Dockerfile`
