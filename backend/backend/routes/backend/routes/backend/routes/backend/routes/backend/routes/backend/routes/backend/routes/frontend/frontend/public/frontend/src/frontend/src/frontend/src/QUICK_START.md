# ⚡ Быстрый старт на Railway (5 минут)

## 1️⃣ Railway развёртывание

1. Открой https://railway.app
2. **Start Project** → **Deploy from GitHub**
3. Выбери `simnesim1-coder/telegram-shop-miniapp`
4. **Deploy** ✅

Railway сам:
- Прочитает `Dockerfile`
- Установит зависимости
- Запустит приложение
- Выдаст URL вида `https://xxx.railway.app`

## 2️⃣ Telegram Mini App

1. @BotFather
2. `/mybots` → твой бот → **Bot Settings** → **Menu Button** → **Web App**
3. **URL** вставь URL из Railway
4. **Сохрани**

## 3️⃣ Готово!

Открой своего бота в Telegram → нажми кнопку меню → **Mini App** 🚀
